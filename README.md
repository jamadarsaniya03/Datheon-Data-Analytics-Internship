# Task 1: Exploratory Data Analysis on Superstore Retail Sales

## Internship
Datheon – Data Analytics & Power BI Internship

## Objective
Perform exploratory data analysis on retail sales data to identify sales trends, customer purchasing behavior, regional performance and profitability.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Dataset
Superstore Retail Sales Dataset.

## Data Preprocessing
- Identified 806 invalid/non-sales rows.
- Removed invalid rows using Row ID validation.
- Checked duplicate records.
- Converted Order Date and Ship Date into datetime format.
- Extracted Year, Month, Month Name and Year-Month.
- Identified 11 missing Postal Code values.

## Analysis Performed
1. Business KPI analysis.
2. Category-wise sales and profit analysis.
3. Region-wise sales analysis.
4. Customer segment analysis.
5. Monthly sales trend analysis.
6. Discount sensitivity analysis.

## Key Performance Indicators
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Total Customers: 793
- Total Quantity: 37,873
- Profit Margin: 12.47%

## Business Insights
- Technology generated the highest category sales.
- West generated the highest regional sales.
- Consumer customers generated the highest revenue.
- Monthly analysis identified seasonal sales patterns.
- Discount and profit had a negative correlation of -0.219.

- EDA_Analysis.ipynb
- Cleaned dataset
- Data profile
- Five visualization charts
- Executive business findings

## Conclusion
The project demonstrates how Python-based exploratory data analysis can transform raw retail data into meaningful business insights and support data-driven decisions.
